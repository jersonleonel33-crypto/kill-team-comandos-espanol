# Kill Team Comandos Español

Recursos en español de los 44 comandos presentes en la copia de Workshop 3336372255. Fuentes oficiales de [Warhammer Community](https://www.warhammer-community.com/en-gb/downloads/kill-team/), revisadas el 10/10/2026.

Se mantienen las dimensiones originales y las cuadrículas de los atlas. Las correcciones ES/EN están registradas en la auditoría. Los reversos decorativos son traducciones propias.

El JSON privado de la partida y los datos de cuenta no se publican en este repositorio. Actualizar las imágenes no cambia las fichas internas de partidas previamente guardadas.
