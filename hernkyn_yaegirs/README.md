# Yaegirs Hernkyn

Cartas en español para la copia local de KT3 operatives, ploys and equipment (Workshop 3336372255).

Fuente: [Warhammer Community — descargas de Kill Team](https://www.warhammer-community.com/en-gb/downloads/kill-team/), idioma Español. Versión del equipo publicada el 26/08/2026.

Se mantienen los píxeles originales de cada recurso (950 × 550 o 600 × 950), con ajuste de bordes y sin deformar las letras. Se conservan CardID, CustomDeck, escala, miniaturas y Lua.

Incluye agentes, selección de comando, reglas de facción, ardides, equipo y guía de marcadores, además del reverso de Habilidosos. Los reversos decorativos originales se conservan.

Corrección documentada: el PDF español omite el número en «Certera» para Cartuchos bólter estabilizados. Nuestra carta indica «Certera 1», conforme a la regla y errata inglesas actuales («Accurate 1»).

Estos archivos actualizan las imágenes. Las estadísticas internas y nombres de las miniaturas no se actualizan automáticamente. La carga dentro de TTS debe comprobarse en la partida.
