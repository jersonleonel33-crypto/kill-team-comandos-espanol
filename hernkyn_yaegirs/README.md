# Yaegirs Hernkyn

25 imágenes en español para la copia local de KT3 operatives, ploys and equipment (Workshop 3336372255).

Fuente: [Warhammer Community — descargas de Kill Team](https://www.warhammer-community.com/en-gb/downloads/kill-team/), PDFs oficiales del equipo en español e inglés, actualizados el 26/08/2026. Comprobados el 10/10/2026.

Se mantienen las dimensiones originales: 950 × 550 o 600 × 950. Se ajustan los bordes sin deformar las letras. Incluye agentes, selección, reglas de facción, ardides, equipo, guía de marcadores y reverso de Habilidosos. Los reversos decorativos originales se conservan.

Dos omisiones del PDF español se corrigen contra la versión inglesa actual: «Certera 1» para Cartuchos bólter estabilizados y la condición «tras la primera fase» de Aventurero veterano del Theyn.

La partida local «Kill Team Comandos Español - Yaegirs Hernkyn» incorpora además la actualización manual de las 13 fichas internas: nombres, armas, habilidades y movimiento de 5 pulgadas. Se conservan variantes de armamento, identificadores, CardID, CustomDeck, escala, modelos y código Lua. Se retiran de esas fichas las antiguas definiciones de armas de KT2021; las etiquetas de reglas corresponden ahora a las cartas actuales. Los campos que los scripts leen como APL/MOVE/SAVE/WOUNDS se conservan por compatibilidad.

Las imágenes de este repositorio no actualizan automáticamente las fichas internas de una partida ya guardada. La nueva partida debe cargarse y revisarse en Tabletop Simulator.
